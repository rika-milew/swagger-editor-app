## Getting Started

- **Clone this repository**
  ```
  git clone https://github.com/rika-milew/swagger-editor-app.git
  ```
- **Install dependencies**

  ```
  npm install
  ```

  or

  ```
  yarn install
  ```

- Start development server
  ```
  npm run dev
  ```
